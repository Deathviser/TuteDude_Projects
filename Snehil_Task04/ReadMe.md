# Image Card with Gradient Button

A simple webpage made with HTML and CSS. It shows an image with a gradient "Click Me" button below it, centered on the screen with no scrolling.

## Live Link


## Technologies Used

- HTML
- CSS

## Features

- Image and button centered with 25% space on left and right
- 10% space on top and bottom
- Gradient button
- No page scroll

## How to Run

1. Keep `index.html`, `style.css` and the `images` folder together.
2. Open `index.html` in a browser.
