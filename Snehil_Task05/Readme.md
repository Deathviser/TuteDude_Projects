# Laundry Service – Hero Section

A responsive hero section for a laundry service web application, built with plain HTML and CSS.

## Live Demo

https://deathviser.github.io/TuteDude_Projects/Snehil_Task05/

## Features

- Navbar with logo (left), links (Home, Services, About Us, Contact Us) and username (right), built using `display: inline` / `inline-block` (no flexbox)
- Hero section with two divs: text and call-to-action button on the left, laundry image on the right
- Sized with viewport units (`vw` / `vh`) so the whole section fits the screen without scrolling

## Project Structure

```
├── index.html
├── style.css
└── asset/
    └── image.png
```

## How to Run

1. Download or clone this repository.
2. Keep the folder structure as shown above.
3. Open `index.html` in your browser.
