# Laundry Wallah / Laundry Mart

A simple HTML webpage for a laundry service, built as part of the TuteDude HTML task.

## Description

The page introduces Laundry Wallah / Laundry Mart and shows its services, prices, and a booking form. It uses only HTML, with no CSS or JavaScript.

## Sections

- **Header:** welcome heading
- **About:** short introduction to the service
- **Image:** a laundry image
- **Services:** list of services offered
- **Price List:** table of services and prices
- **Book Now:** form with name, email, and phone (all required)
- **Footer:** contact email

## Files

- `index.html`: the main webpage
- `laundry.jpg`: image used on the page
